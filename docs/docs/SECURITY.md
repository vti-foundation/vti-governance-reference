# Security Policy

## Purpose

VTI Foundation Inc. takes the security of publicly released reference materials seriously.

This repository currently contains architecture documentation, reference interfaces, examples, and related implementation materials.

Security reporting should be limited to issues that affect material actually published in this repository.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Where GitHub Private Vulnerability Reporting is enabled for this repository, use that mechanism.

If private vulnerability reporting is not available, use the official VTI Foundation Inc. contact channel identified at:

https://vtifoundation.org

When reporting a vulnerability, include:

* a clear description of the issue;
* the affected file, component, or version;
* steps to reproduce the issue where applicable;
* potential security impact;
* any known mitigations; and
* whether the issue has been disclosed elsewhere.

Please avoid including unnecessary sensitive or personal information.

## Supported Material

Security review currently applies to the public material contained in this repository.

As implementation code is added, supported versions and affected components may be identified here.

## Out of Scope

The following are outside the scope of this repository security policy unless expressly incorporated into the repository:

* unpublished VTI standards;
* certification systems;
* internal VTI infrastructure;
* proprietary implementations;
* third-party blockchain or network infrastructure;
* third-party wallets, nodes, validators, APIs, or smart contracts;
* social-engineering attacks;
* denial-of-service testing against systems not expressly authorized for testing; and
* attempts to obtain confidential or unpublished VTI material.

Security reports should not be used to request disclosure of proprietary methods, unpublished technical details, or other protected intellectual property.

## Coordinated Disclosure

VTI Foundation Inc. may request reasonable time to investigate and address a reported issue before public disclosure.

Submitting a report does not authorize access to systems, data, accounts, or infrastructure beyond what the reporter is otherwise permitted to access.

## Security and Conformance

Discovery or remediation of a security issue in this repository does not establish, modify, or determine conformance with any VTI Foundation Inc. standard or certification program.

See `NOTICE.md` for additional standards, intellectual-property, and certification boundaries.
